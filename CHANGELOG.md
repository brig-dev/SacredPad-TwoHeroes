# Changelog

## 0.9.0 beta

First public release.

- License: GPL-3.0-or-later since 23 November 2026 (the first upload, on 10 November 2026, was MIT).
- Complete controller support for Sacred Gold: movement, automatic target, aim with the right stick, combat arts on
  five buttons, potions, weapon sets, minimap, item names, pick up all, horse, zoom, doors and portals by walking into
  them, cursor mode for every game window, dialogues, button symbols on the taskbar, in-game help, rumble.
- Couch co-op on one screen: "Two players" in the main menu, hero 2 from your saved heroes with the second controller,
  shared camera, player markers, second taskbar, two inventories with two game cursors, shared merchant and chest,
  combo master for both, shared experience, gold, map and healing, loot and rewards for both classes, revive,
  companions view, hero 2 saved in its own file.
- Experimental split screen (two 1280x720 windows, needs a screen at least 2560 wide and a copy of the game folder);
  the "Two players" menu tells when the screen is too narrow or the copy is missing.
- Texts in English, Italian, German, French and Spanish, following the game's language.
- A window at start when `Sacred.exe` is not the supported one; the user folder is never written in the log.
