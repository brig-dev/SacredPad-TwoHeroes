# SacredPad: Two Heroes - controls

Button names are Xbox ones; PlayStation in brackets. In the game, hold **Menu** for the same help with a picture of
your controller (D-pad left/right there changes the button style: Xbox, DualSense, Steam).

## In the game world

| Button | Press | Hold |
|---|---|---|
| Left stick | move | |
| Left stick click (L3) | minimap | |
| Right stick | aim: A and the arts go to the enemy in that direction | |
| Right stick click (R3) | item names (Alt) | |
| A (Cross) | attack the chosen enemy; with no enemies: talk, open, pick up (again: the next one) | + left stick: choose the target |
| B (Circle) | pick up all | call, mount or leave the horse |
| X (Square), Y (Triangle), RB (R1), RT (R2), LT (L2) | combat art of taskbar slot 1, 2, 3, 4, 5 | |
| LB (L1) | healing potion | |
| D-pad up | concentration potion (yellow) | zoom in |
| D-pad down | Mentor potion (blue) | zoom out |
| D-pad left / right | previous / next weapon set | |
| View (Share/Create) | cursor mode on / off | inventory |
| Menu (Options) | game menu | this help |

The potions of the D-pad can be changed in `SacredPad.ini` (`DpadUpPotion`, `DpadDownPotion`).

## Cursor mode (inventory, shops, chests, dialogues, menus)

It turns on by itself when a game window opens and off when all are closed.

| Button | Action |
|---|---|
| Left stick | move the cursor |
| Right stick | move the cursor slowly |
| D-pad | jump between slots and buttons |
| A | click: pick up and drop |
| B | right click: use, equip |
| X | at a merchant: sell the item under the cursor |
| Y | close the window / leave the shop |
| LB / RB | previous / next tab (inventory, arts, combos; also at merchants) |
| View | back to the game |

In dialogues with characters, A accepts (OK, Accept) and B declines.

## Player 2

Player 2 has the same controls as player 1, for hero 2, with these differences:

| Button | Action |
|---|---|
| View | hero 2's cursor mode (a game cursor of their own, with a "2" next to it) |
| View held | hero 2's inventory, on the right |
| Menu | game menu, used with player 2's D-pad, A and B |
| Menu held | the help, with player 2's controller |

With both inventories open, each player has their own cursor and their own hand: both can drag items at the same time, and
an item dropped on the other column goes into the other hero's backpack. Y closes your own column only.
